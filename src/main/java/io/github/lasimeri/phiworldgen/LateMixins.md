# LateMixins.java

The mixins into other mods' classes, which can only apply once those mods are
loaded (GTNHMixins' `@LateMixin` loader, present through UniMixins):
`mixins.phiworldgen.late.json`, package `latemixins`. With RWG loaded: the
caves accessor, the profile phases and the card path for RWG's generator.
