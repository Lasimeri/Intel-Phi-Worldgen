# CommandPhiwg.java

The server command `/phiwg`, for the console or an operator:

- **`pregen <radius> [dx dz]`:** resets the profile, then loads every chunk of the (2 radius + 1)² square centred `dx`, `dz` chunks from the spawn chunk, on the server thread, through `ChunkProviderServer.loadChunk`. The default centre, 64, 0, keeps clear of the 25 x 25 chunks the server prepares around spawn at start. A chunk not yet on disk is generated by `provideChunk`, and populated once its neighbours exist. It prints the wall time, chunks per second, the seed and `GenProfile`'s report.
- **`report`:** the profile since the last reset.
- **`reset`:** zeroes the profile.
- **`capture <name> [biome radius]`:** calls the overworld generator's `provideChunk` directly on a chosen set of chunks with `Capture` on, writing `~/.cache/phiworldgen/capture/<name>/`. Nothing enters the world; only the structure generators remember structure starts. The set is:
  - the 6 x 6 chunks around the origin (both signs of x and z);
  - eight chunks past each generator's first `% 16777216` wrap. Octave 0 of scale s wraps from |chunk| >= 2²⁴ / 4s, which is 6,128 for 684.412, 20,972 for 200 and 490,266 for 8.55515; there is also one at 1,800,000, inside the 30,000,000-block border;
  - the first chunk found for each biome id within the biome radius (default 256 chunks), sampling a chunk centre every 4 chunks.

  It prints the files written, how many blocks the caves and the ravines changed and in how many chunks, and the biome ids found.
- **`verify <name>`:** `CaptureVerify` on that capture.

Everything printed also goes to the log
(`run/server/logs/fml-server-latest.log`).
